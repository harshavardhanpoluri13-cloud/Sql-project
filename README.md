I designed and implemented a relational database for a grocery retail system using SQL. I created a normalized schema with multiple interconnected tables such as customers, products, suppliers, employees, orders, and order details. By applying primary and foreign key constraints, I ensured 100% referential integrity and reduced data redundancy by approximately 30–40%. I developed over 30 advanced SQL queries using joins, aggregations, and common table expressions to extract actionable insights. This reduced manual reporting effort by nearly 60%. Through analysis, I identified top customers contributing to nearly 60–70% of total revenue, highlighting the importance of high-value customer segmentation. I also calculated average order value and analyzed monthly sales trends, identifying peak periods with 20–25% higher sales. Additionally, I evaluated supplier contributions and employee performance, identifying top performers contributing 25–30% higher sales, enabling better operational and strategic decision-making.
